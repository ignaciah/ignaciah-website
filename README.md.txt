Deploy
Option 1: Cloudflare Pages (connected to GitHub - Recommended)
1. Create a new GitHub repo named ignaciah-website
2. Push this code
3. In Cloudflare Dashboard > Workers & Pages > Create Application > Pages > Connect to Git
4. Select your GitHub repo ignaciah-website
5. Build settings: Framework preset = None, Build command = (leave empty), Output directory = /
6. Deploy, then add custom domain ignaciah.com


Any push to main branch will auto-deploy.
Option 2: Manual Upload
Just upload index.html to Cloudflare Pages > Upload assets.
